# FloraSign AI - แอปพลิเคชันจดจำและแสดงข้อมูลดอกไม้

## ภาพรวมของแอปพลิเคชั่น

**FlorasignAI** เป็นแอปพลิเคชั่น Flutter ที่ใช้สำหรับการจดจำและศึกษาเกี่ยวกับดอกไม้ โดยมีฟีเจอร์การใช้ AI ในการตรวจจับดอกไม้จากรูปภาพ

## หน้าจอและฟังก์ชันต่างๆ

### 1. **Start Screen** (`start_screen.dart`)
- หน้าจอเริ่มต้นของแอป
- แสดงโลโก้และปุ่ม "เริ่มต้นใช้งาน"
- ใช้รูปพื้นหลังจาก `asset/start_screen.png`

### 2. **Home Screen** (`home_screen.dart`) 
- หน้าจอหลักที่มีเมนูต่างๆ
- มีปุ่มนำทางไปยัง:
  - กล้องถ่ายรูป (Camera)
  - ดอกไม้วันเกิด (Birth Flowers)
  - ดอกไม้ยอดนิยม (Popular Flowers)
  - รายการที่ชื่นชอบ (Favorites)

### 3. **Camera Screen** (`camera_screen.dart`)
- ใช้กล้องถ่ายรูปหรือเลือกรูปจากแกลเลอรี่
- ส่งรูปไปยัง AI API เพื่อตรวจจับดอกไม้
- แสดงผลการตรวจจับและนำทางไป Flower Detail

### 4. **Birth Flowers Screen** (`birth_flowers_screen.dart`)
- แสดงดอกไม้ประจำวันต่างๆ
- มีข้อมูลคงที่ (static) ของดอกไม้ 7 วัน
- จันทร์: ดอกดาวเรือง, อังคาร: ดอกอิกซอร่า, เป็นต้น

### 5. **Popular Flowers Screen** (`popular_flowers_screen.dart`)
- แสดงดอกไม้ยอดนิยม 5 ชนิด
- กุหลาบ, เบญจมาศ, คาร์เนชั่น, เยอบีร่า, ลิลลี่
- มีข้อมูลการใช้งานและความหมายของแต่ละดอก

### 6. **Favorites Screen** (`favorites_screen.dart`)
- แสดงรายการดอกไม้ที่ผู้ใช้เพิ่มเป็นรายการโปรด
- สามารถลบออกจากรายการโปรดได้
- ดึงข้อมูลจากฐานข้อมูลท้องถิ่น

### 7. **Flower Detail Screen** (`flower_detail_screen.dart`)
- แสดงรายละเอียดของดอกไม้
- ความหมายตามสี, การใช้งาน
- สามารถเพิ่ม/ลบจากรายการโปรดได้

## ระบบฐานข้อมูล

แอปใช้ **SQLite** เป็นฐานข้อมูลท้องถิ่น:

### ตารางฐานข้อมูล:
1. **flowers** - เก็บข้อมูลดอกไม้ทั้งหมด
2. **favorites_cache** - แคชรายการโปรด
3. **sync_log** - บันทึกการซิงค์ข้อมูล
4. **data_version** - ติดตามเวอร์ชันข้อมูล

### ข้อมูลดอกไม้:
- นำเข้าจากไฟล์ `asset/data/flowers.json`
- เก็บข้อมูลเป็น Base64 สำหรับรูปภาพ

## โครงสร้างไฟล์และหน้าที่

### Models (`lib/models/`)
- **`flower.dart`** - โมเดลข้อมูลดอกไม้, การแปลง JSON/Map/Database

### Services (`lib/services/`)
- **`api_service.dart`** - เชื่อมต่อ AI API สำหรับตรวจจับดอกไม้
- **`database_helper.dart`** - จัดการฐานข้อมูล SQLite
- **`favorites_service.dart`** - จัดการรายการโปรด

### Screen Files (`lib/`)
- **`main.dart`** - จุดเริ่มต้นของแอป, การตั้งค่าฐานข้อมูล
- **`start_screen.dart`** - หน้าจอเริ่มต้น
- **`home_screen.dart`** - หน้าจอหลัก/เมนู
- **`camera_screen.dart`** - หน้าจอกล้องและการตรวจจับดอกไม้
- **`birth_flowers_screen.dart`** - หน้าจอดอกไม้ประจำวัน
- **`popular_flowers_screen.dart`** - หน้าจอดอกไม้ยอดนิยม
- **`favorites_screen.dart`** - หน้าจอรายการโปรด
- **`flower_detail_screen.dart`** - หน้าจอรายละเอียดดอกไม้

### Assets (`asset/`)
- **`data/flowers.json`** - ข้อมูลดอกไม้ทั้งหมดในรูปแบบ JSON
- **รูปภาพดอกไม้** - ไฟล์ .png ของดอกไม้ต่างๆ
- **รูปพื้นหลังและโลโก้** - `start_screen.png`, `logo.png`

### Font Files (`lib/fonts/`)
- ฟอนต์ต่างๆ สำหรับการแสดงผลภาษาไทยและอังกฤษ

## เทคโนโลยีและ Dependencies

### เทคโนโลยีหลัก:
1. **Flutter** - Framework สำหรับพัฒนาแอปมือถือ
2. **SQLite** - ฐานข้อมูลท้องถิ่น (sqflite package)
3. **AI Backend** - `https://cr2amx-flower-detector.hf.space/api/detect`

### Dependencies สำคัญ:
- `camera: ^0.10.5+5` - การใช้กล้อง
- `http: ^1.1.0` - การเชื่อมต่อ API
- `sqflite: ^2.3.0` - ฐานข้อมูล SQLite
- `path_provider: ^2.1.1` - การจัดการเส้นทางไฟล์
- `image_picker: ^1.0.7` - การเลือกภาพ
- `shared_preferences: ^2.2.2` - การเก็บข้อมูลแบบ Key-Value

## วิธีการทำงาน

1. **การเริ่มต้น**: แอปจะโหลดฐานข้อมูลและนำเข้าข้อมูลดอกไม้จาก JSON
2. **การตรวจจับดอกไม้**: ใช้กล้องหรือเลือกภาพ → ส่งไป AI API → ได้ผลลัพธ์
3. **การจัดเก็บ**: ข้อมูลโปรดจะถูกเก็บในฐานข้อมูล SQLite ท้องถิ่น
4. **การแสดงผล**: แสดงข้อมูลดอกไม้พร้อมรูปภาพและความหมาย

## การใช้งาน

แอปนี้เหมาะสำหรับ:
- ผู้ที่สนใจศึกษาเกี่ยวกับดอกไม้
- การเรียนรู้ความหมายและการใช้งานของดอกไม้
- การจดจำชนิดดอกไม้ด้วยเทคโนโลยี AI
- การสะสมข้อมูลดอกไม้ที่ชื่นชอบ
